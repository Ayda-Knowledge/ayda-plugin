# Security

## Report a problem

Report a security problem in this plugin through GitHub's private
vulnerability reporting: open the **Security** tab of this repository and
select **Report a vulnerability**. Do not open a public issue.

Include the skill or file, what an attacker can do, and the steps to
reproduce it. We reply within five working days.

## Scope

This repository holds skills (instruction text) and the plugin manifest. A
problem in the Ayda server itself, such as access control or sign-in, is also
welcome through the same channel; we route it to the product team.

## What the plugin can do

The plugin connects only to the Ayda installation whose host you enter. Its
only writes are your own open-loop verdicts and the memory sentences you
approve. [README.md](README.md#data-and-privacy) describes both.
